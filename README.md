# CodeOrbit BMI Calculator App

A modern, responsive Android Body Mass Index (BMI) calculator application built with **Kotlin**, **Jetpack Compose**, and **Clean Architecture**.

## 📱 Features
- **BMI Calculation**: Calculates exact BMI value from height (cm) and weight (kg).
- **Health Category Classification**: Categorizes BMI into *Underweight*, *Normal*, *Overweight*, or *Obese* with visual color coding.
- **Input Validation**: Prevents invalid numbers, empty inputs, or out-of-range values with real-time error messages.
- **Clean Architecture**: Decoupled Domain (Use Cases, Models), Presentation (ViewModel, StateFlow, Compose UI), and UI state handling.
- **Unit Testing**: Comprehensive unit tests for business logic and input validation use cases.

## 🛠️ Technologies Used
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3)
- **Architecture**: Clean Architecture (Domain, Presentation)
- **State Management**: ViewModel & StateFlow
- **Testing**: JUnit 4

## 🚀 Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/ubaidraye/CodeOrbit_BMI_Calculator_App.git
   ```
2. Open **Android Studio** (Ladybug / 2024.2+ recommended).
3. Let Gradle sync automatically.
4. Select an emulator or physical device (Android 7.0 / API 24+).
5. Click **Run 'app'** (`Shift + F10`).
